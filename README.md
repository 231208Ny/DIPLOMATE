# DIPLOMATE 🌍

### Learn Diplomacy. Understand the World. Shape the Future.

DIPLOMATE is an educational web application designed to introduce students to diplomacy, international relations, and Model United Nations (MUN). It provides interactive learning features to help students explore global issues and develop their understanding of international affairs.

🌐 **Live Website:** https://diplomate-bay.vercel.app/  
💻 **GitHub Repository:** https://github.com/231208Ny/DIPLOMATE

---

## ✨ Features

- **Diplomacy Assistant:** Get educational responses to questions about diplomacy, MUN, and international relations.
- **MUN Learning Support:** Explore concepts such as opening speeches, resolutions, and diplomatic discussions.
- **Country Comparison:** Explore country-related information through comparison features.
- **MUN Simulation:** Experience educational activities inspired by Model United Nations.
- **Global Affairs Learning:** Explore topics such as the United Nations, ASEAN, foreign policy, climate change, and human rights.

> Note: The Diplomacy Assistant currently uses programmed responses for recognized topics and is not powered by a live generative AI model.

## 🎯 Project Goals

DIPLOMATE aims to make diplomacy and international relations more accessible to students, particularly beginners who want to understand global affairs and participate in MUN.

The project encourages students to:
- Understand international issues.
- Develop diplomatic thinking.
- Improve their knowledge of MUN.
- Explore international cooperation.
- Become informed global citizens.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/231208Ny/DIPLOMATE.git
   ```

2. Navigate to the project folder:

   ```bash
   cd DIPLOMATE
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Build for Production

```bash
npm run build
```
